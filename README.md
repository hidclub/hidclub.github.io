# 수행 레퍼런스 홈페이지

승인받은 레퍼런스만 소개하는 정적 사이트입니다. 서버나 빌드 도구가 필요 없습니다.

## 파일
- `index.html` 페이지 틀
- `style.css` 디자인
- `app.js` 목록·상세 화면
- `data.js` 상호, 소개 문구, 레퍼런스 데이터 (여기만 고치면 됩니다)

## 레퍼런스 추가·사진 넣기
1. 노션 과업 관리 표에서 홈페이지 칸이 "승인"인 것만 추가합니다.
2. `data.js` 의 `REFS` 맨 위에 항목을 복사해 고칩니다.
3. 사진은 `img/` 폴더에 넣고 `image: "img/파일명.jpg"` 로 적습니다. 비워 두면 포스터형 카드가 나옵니다.
4. 금액, 계좌, 전화번호, 개인 이름은 적지 않습니다.

## 미리 보기
```bash
python -m http.server 8000
```
브라우저에서 http://localhost:8000 을 엽니다.

## 깃허브 페이지로 공개
저장소 이름을 `hidclub.github.io` 로 만들면 주소가 `https://hidclub.github.io` 가 됩니다.
(저장소 이름은 `계정이름.github.io` 여야 하고, 끝에 점(.)이 붙지 않아야 합니다.)
저장소 Settings → Pages 에서 Branch 를 `main` / root 로 지정합니다.
도메인을 구매한 뒤에는 Pages 설정에 도메인을 연결합니다.
